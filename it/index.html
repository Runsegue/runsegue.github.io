Framework · MIT · Python stdlib

Il segue dopo
un run riuscito

Runsegue aggiunge una nota opzionale e trasparente in stdout dopo utilizzi reali. Qualsiasi agente AI che esegue il tuo CLI la legge e può chiedere all'utente — una volta — feedback o iscrizione email. Nessun SDK LLM. Nessuna regola in AGENTS.md.

GitHub Come funziona

Qualsiasi LLM

Gli agenti leggono già stdout. Runsegue scrive lì — universale per design.

Opt-in umano

L'agente chiede in chat. L'utente decide. Runsegue non invia dati in silenzio.

Intake pluggable

POST /v1/intake — il tuo backend, qualsiasi stack.

Flusso

CLI ok → nota Runsegue in stdout
     → agente legge output
          → utente accetta o rifiuta in chat
               → agente esegue: feedback "..." o feedback --decline
                    → POST /v1/intake (server opzionale)
