Framework · MIT · Python stdlib

The segue after
a successful CLI run

Runsegue adds an optional, transparent note to stdout after real usage. Any AI agent that runs your CLI can read it and ask the user once — for feedback or email signup. No LLM SDK. No rules in AGENTS.md.

View on GitHub How it works

Any LLM

Agents already read terminal output. Runsegue writes there — universal by design.

Opt-in human

The agent asks in chat. The user decides. Runsegue never sends data silently.

Pluggable intake

POST /v1/intake — your backend, any stack.

Flow

CLI succeeds → Runsegue note in stdout
     → agent reads output
          → user accepts or declines in chat
               → agent runs: feedback "..." or feedback --decline
                    → POST /v1/intake (optional server)
